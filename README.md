# Интерактивная презентация

Внутренняя браузерная сцена 1920×1080: слайд 1732×1080 и панель стикеров 188×1080. Сцена автоматически вписывается в любое окно с сохранением пропорций 16:9.

## Запуск

Требуется Node.js 22+.

```bash
pnpm install
pnpm dev
```

Production-сборка:

```bash
pnpm build
```

Shader-слои экспортированы из Figma как локальные полноразмерные PNG, поэтому выглядят одинаково и не зависят от поддержки WebGPU. Переключение слайдов работает кнопками внизу и стрелками клавиатуры. Стикеры перетаскиваются из правой панели; после размещения их можно двигать за центр и отклеивать за край.

Sticker Forge зафиксирован на ревизии `068caa49eef69745564a5debbc01bab3fcd31042`. Лицензии находятся в `public/vendor/sticker-forge/`.

Последний слайд «Прототип» соответствует Figma `202:7845`. Кликабельный прототип из папки `Прототип` скопирован без изменений в `public/prototype` и встроен в экран телефона через iframe. Текстовый стикер находится в правой панели. При обновлении исходного прототипа обновите копию в `public/prototype`.

Папки на слайде «Проекты» собраны по слоям Figma с оригинальными рамками фотографий и полупрозрачной передней частью. Масштаб сцены задаётся через CSS zoom без постоянного transform-слоя. Все стикеры экспортированы отдельно с прозрачностью в повышенном разрешении; информационные плашки используют один canvas и при отклеивании не переключаются на другую картинку. В Sticker Forge отключены внутренние поля источника (padding: 0) и используется отрисовка с учётом devicePixelRatio.
